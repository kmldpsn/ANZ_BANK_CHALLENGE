# ANZ_BANK_CHALLENGE

This project focuses on analyzing customer data to predict the likelihood of loan default for ANZ Bank. The goal is to help the bank make smarter, data-driven lending decisions while minimizing financial risk.
Using machine learning models, we classify whether a customer is likely to repay a loan or default based on historical data.

## Objectives
Predict loan default risk (0 = Approved, 1 = Not Approved / Default)
Identify key factors influencing loan repayment
Compare multiple machine learning models
Provide actionable business insights for decision-making
📊 Dataset

The dataset includes customer and financial information such as:

## Demographics (age, income, etc.)
Credit history
Loan details
Transaction patterns
Dataset is taken from kaggle

## Tools & Technologies
Python
Pandas, NumPy – Data manipulation
Matplotlib, Seaborn – Data visualization
Scikit-learn – Machine learning models
